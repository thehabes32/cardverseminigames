🤖 AI Smart Import
Copy any card data from PSA Pop Report, CardLadder, eBay sold listings, or anywhere — paste it here and AI extracts the cards automatically.
How to get PSA Pop data:
  1. Go to psacard.com/pop
  2. Search for a player (e.g. "LeBron James")
  3. Open a set (e.g. "2003-04 Topps Chrome")
  4. Select all the text on the page (Cmd+A) and copy it (Cmd+C)
  5. Paste it below and hit Parse with AI
Works with PSA, CardLadder, eBay, plain text — anything
Claude reads the text and extracts all cards automatically
📊 CSV Import
Upload a CSV file or paste CSV data directly. Player and pop count are required.
CSV Format:
  1. Required columns: player, pop
  2. Optional: year, set, grade, sport (basketball/football/baseball/hockey/pokemon)
  3. First row should be column headers
player,year,set,grade,pop,sport

Patrick Mahomes,2017,Panini Prizm RC,PSA 10,3201,football
